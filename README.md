# KAI Upgrade Child

Custom WordPress child theme for the KAI Upgrade website.

The theme is designed to work with the **Hello Elementor** parent theme and requires the **Elementor** plugin.

## Requirements

- WordPress
- Hello Elementor
- Elementor
- PHP compatible with the current WordPress installation

## Parent Theme

This is a child theme of:

`hello-elementor`

The Hello Elementor theme must be installed on the WordPress website.

## Elementor

Elementor is required for the website layout and page building.

The theme contains custom styling, templates and functionality that extend the base Hello Elementor theme and Elementor.

## Installation

1. Install WordPress.
2. Install and activate the Hello Elementor theme.
3. Install and activate Elementor.
4. Upload the `kai-upgrade-child` directory to:

   `wp-content/themes/`

5. Activate **KAI Upgrade Child** in:

   Appearance → Themes
